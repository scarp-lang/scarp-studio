# Explorer developer tool directory

The primary file Explorer and open-editor list stay above Developer Tools.
The directory exposes all secondary tools by default. Filter by category
or search by name, purpose or keywords. Enter reveals the single matching
tool; Escape clears the current search and category. The index lists
matching tools with a short description and a pin control.

A reveal focuses an available control of the mounted panel and scrolls it
into view; it does not click, execute or confirm anything automatically.
Recent and pinned shortcuts can reveal a tool hidden by current filters.
Reset clears session pins, recent choices and filters, not editor settings.

Filtered panels remain mounted and retain local expansion, selection and
review state. Independent freshness guards still apply. This is a visibility
projection, not a performance suspension mechanism. Pins and recent IDs
are in-memory session state only, not persisted or exported.
